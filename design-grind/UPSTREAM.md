# Attribution and adaptation

The review cycle adapts Theo Browne's [council](https://github.com/t3dotgg/tstack/blob/1085050f3baed1ac724caa4a8166145fb2ac88af/skills/council/SKILL.md), pinned to tstack commit `1085050f3baed1ac724caa4a8166145fb2ac88af`. The [complete MIT notice](LICENSE) travels with this skill.

The adaptation retains preparation before review, reviewer selection and availability handling, read-only independent feedback, honest round scores, fresh reviews after fixes, scope control, and PR-description reporting. It adds UI state coverage, the design rubric, revision-linked captures, finding decisions, a passing target, and a before/after board with saved user choices.
