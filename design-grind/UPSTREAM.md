# Attribution and adaptation

The review cycle adapts Theo Browne's [council](https://github.com/t3dotgg/tstack/blob/1085050f3baed1ac724caa4a8166145fb2ac88af/skills/council/SKILL.md), pinned to tstack commit `1085050f3baed1ac724caa4a8166145fb2ac88af`. The [complete MIT notice](LICENSE) travels with this skill.

The adaptation uses UI state captures, a design rubric, and local reviewer settings. It invokes the companion [`before-after-review`](../before-after-review/SKILL.md) skill for the deterministic decision board and applying the user's selections.
